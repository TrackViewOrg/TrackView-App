# Features Directory

This directory contains the core business logic of the application, organized by feature.

## Structure

Each feature folder should ideally contain:

- `components/`: React components specific to this feature.
- `hooks/`: Custom React hooks for this feature.
- `lib/`: Utility functions and helpers specific to this feature.
- `actions.ts`: Server actions for this feature.
- `types.ts`: TypeScript type definitions for this feature.

## Features

- **auth**: Authentication logic (login, signup, password reset).
- **sessions**: Racing session management, analysis, and visualization.
- **dashboard**: Dashboard layout and widgets.
- **analytics**: Data analysis and reporting.
- **map**: Map visualization and interaction logic.
